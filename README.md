# Nebraska Public Expenditure Analysis

## Overview

This project analyzes publicly available Nebraska expenditure data to identify spending patterns, major categories, and trends that can support transparent reporting and informed budget discussions.

## Business Question

How are expenditures distributed across categories, agencies, or time periods, and what patterns should stakeholders investigate further?

## Tools Used

- Python
- pandas
- Jupyter Notebook / Google Colab
- Data visualization

## Analysis Process

1. Reviewed the dataset structure and data types.
2. Cleaned missing values and standardized relevant fields.
3. Analyzed spending by applicable categories, agencies, or time periods.
4. Created visualizations to communicate key trends.
5. Summarized insights for a nontechnical audience.

## Skills Demonstrated

Data cleaning, data validation, exploratory data analysis, aggregation, visualization, documentation, and stakeholder-oriented reporting.

## Data Note

This project uses public data for educational and portfolio purposes. No confidential or personally identifiable information is included.
